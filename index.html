AegisQR Cryptographic Security Standard

AegisQR is engineered to enable zero-trust, air-gapped data transfers between devices without using the internet, servers, or intermediaries. Every payload is secured using modern authenticated encryption before being converted into optical barcode frames.

AES-256-GCM

Industry-standard Galois/Counter Mode authenticated encryption executed natively via the browser's Web Cryptography API. Ensures both confidentiality and cryptographic integrity.

Proprietary AQR1 Envelope

Packaged with application-specific derivation seeds and cryptographic random 16-byte salts. Standard scanners cannot decipher or interpret the encrypted ciphertext.

DEFLATE Compression

Pre-compresses text, JSON, contacts, and files by 50–80% prior to encryption, packing maximum data density into standard optical QR limits.

Air-Gapped Multi-Frame Stream Protocol

For large files or data exceeding single-frame density (1.2KB+), AegisQR employs the Air-Gap Stream Sequencer (modeled after cryptocurrency hardware wallet standards). The payload is split into synchronized frames cycled at 4–10 FPS. The receiver's camera tracks each frame with live progress HUD and automatically stitches and decrypts the file the moment all frames are received.
